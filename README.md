# Country Noise Map

세계 각 나라를 **주파수(스펙트럼)** 로 만나는 인터랙티브 세계지도입니다.
지도에서 나라를 고르면 그 나라의 랜드마크와 상징 색으로 만든 주파수 화면이 전체 화면으로 펼쳐집니다.
버튼이나 메뉴 없이, 보고 즐기는 것이 목적입니다.

## 기능

**세계지도**
- 대륙별로 하나의 판처럼 합쳐진 지도와, 나라 사이의 가는 경계선
- 휠, 두 손가락 핀치, 드래그로 확대·이동 (Esc 키로 처음 크기로 복귀)
- 확대할수록 나라 이름이 서서히 나타남
- 마우스를 올리면 나라 이름과 은은한 빛막, 지도가 마우스를 따라 살짝 기울어짐
- 뒤에서 느리게 번지는 색 구름과 반짝이는 별
- 25초 동안 입력이 없으면 **감상 모드**가 시작되어 나라를 하나씩 확대해서 비춤

**주파수 화면**
- 나라를 클릭하면 클릭한 지점에서 물결이 퍼지며 전환
- 그 나라의 상징 색(국기 등)이 막대 전체에 그라데이션으로 흐름. 한국은 오방색
- 막대는 그 나라의 랜드마크 실루엣(약 80개국, 112개)과 도시 건물로 이루어진 스펙트럼
- 가운데 중심선은 막대 높이에 맞춰 출렁이는 작은 파형이며, 나라마다 막대 색과 다른 색
- 아래쪽 절반은 위에서 아래로 흐려지는 그림자

**다크 / 라이트 모드**
- 오른쪽 위 버튼으로 전환 (지도와 주파수 화면 어디서나 사용 가능)
- 처음에는 기기의 시스템 설정을 따르고, 한 번 고르면 브라우저에 저장되어 다음 방문에도 유지됨
- 라이트 모드는 눈이 편하도록 부드러운 베이지 배경을 사용
- 주파수 화면도 모드를 따름: 다크는 어두운 무대, 라이트는 베이지 배경에서 읽히도록 색을 자동으로 짙게 조정

**반응형**
- 데스크톱, 태블릿, 모바일(세로·가로)에 맞춰 레이아웃이 바뀜
- 터치 화면에서는 두 손가락 확대, 탭으로 선택, 가로 이동으로 지도 탐색
- 세로로 긴 화면에서는 지도가 확대된 상태로 시작
- 주소창 높이 변화(`dvh`)와 노치(safe area)를 고려

## 실행하기

빌드 과정이 없는 정적 사이트입니다. 폴더를 로컬 서버로 열면 됩니다.

```bash
python3 -m http.server 8000
```

브라우저에서 <http://localhost:8000> 을 엽니다. (`index.html`을 더블클릭해서 열어도 대부분 동작하지만, 로컬 서버를 쓰는 것을 권장합니다.)

지도 데이터와 라이브러리를 CDN에서 불러오므로 **인터넷 연결이 필요**합니다.

### GitHub Pages로 배포하기

저장소 루트에 이 폴더의 파일들이 있으면, 저장소 설정의 **Pages**에서 브랜치(`main`)의 `/ (root)`를 선택하면 바로 공개됩니다.

## 파일 구성

```
country_noise_map/
├── index.html            페이지 구조와 스크립트 연결
├── css/
│   └── style.css         스타일, 전환 효과, 반응형 규칙
└── js/
    ├── main.js           지도, 확대, 주파수 그리기, 전환, 감상 모드
    └── data/
        ├── landmarks.js  나라별 랜드마크 실루엣 데이터 (직접 만든 도형 정의)
        └── palettes.js   나라별 상징 색 팔레트
```

## 직접 바꿔 보기

- **랜드마크 추가**: `js/data/landmarks.js`의 `LANDMARKS`, `EXTRA_LANDMARKS`, `MORE_LANDMARKS`에 나라 이름(영어 공식 약칭)과 도형 목록을 추가합니다. 도형은 `tri`, `rect`, `dome`, `mtn`, `steps`, `teeth` 여섯 가지입니다.
- **상징 색 추가**: `js/data/palettes.js`에 `"나라 이름": ["#색1", "#색2", ...]` 를 추가합니다. 없는 나라는 대륙 색 계열로 표시됩니다.
- **움직임 조절**: `js/main.js` 위쪽의 상수 (`SPEED`, `SMOOTH_RATE`, `IDLE_MS`, `BAR_STEP` 등)를 바꿉니다.
- **색상 테마**: `css/style.css`의 `:root` 변수 (라이트/다크는 `prefers-color-scheme`을 따름)

## 사용한 라이브러리와 데이터

| 이름 | 용도 | 라이선스 |
| --- | --- | --- |
| [d3](https://d3js.org) 7.9.0 | 지도 투영, 확대·이동 | ISC |
| [topojson-client](https://github.com/topojson/topojson-client) 3.1.0 | TopoJSON 처리 | ISC |
| [world-atlas](https://github.com/topojson/world-atlas) 2.0.2 | 세계지도 경계 (Natural Earth 기반) | ISC (원본 Natural Earth는 퍼블릭 도메인) |
| [world-countries](https://github.com/mledoze/countries) 5.1.0 | 나라 이름(한글 포함), 대륙, 수도 등 | ODbL 1.0 |

라이브러리와 데이터는 jsDelivr, cdnjs CDN에서 실행 시점에 불러옵니다. 이 저장소에 포함하지 않습니다.
`world-countries` 데이터는 ODbL 조건(출처 표시 등)을 따릅니다.

랜드마크 실루엣과 상징 색은 이 프로젝트에서 직접 만든 것이며, 실제 모습과 다를 수 있습니다.
